GESP 码力觉醒 — 技术支持与常见问题

适用版本：1.0.0 及以上（iPhone / iPad / Mac）

常见问题 (FAQ)

  • 如何恢复已购买的 Pro 会员，或在多设备间共享会员？
    请使用购买时登录的同一个 Apple ID，打开 App 内的“购买与权益”页面，点击底部 “恢复购买” 即可自动验证并解锁。
  • 如何取消自动续订？
    打开设备“系统设置” → 点击顶部您的姓名（Apple ID） → “订阅” → 选择“GESP 码力觉醒” → 点击“取消订阅”。
  • 为什么首次打开代码沙盒提示需要网络？
    在线代码沙盒通过加密云端编译器完成 C++ / Python 编译与运行测试，需要设备连接互联网；本地题库与刷题复习可离线浏览。
